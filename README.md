# AntiGrav 3D

Godot-4-Version des Antigrav-Rennspiels (rein privat). Echte Beleuchtung, Bildschirm-Spiegelungen auf nasser Fahrbahn, Schatten, Glühen.
GitHub Actions baut bei jedem Push die APK und veröffentlicht sie als Release `build-N`.

- `track.gd` – Streckenmathematik (Neon Night, wie in der HTML-Version)
- `main.gd` – baut Strecke, Stadt, Gleiter, Kamera und Anzeige; Fahrphysik und Gegner
- Gleiter: „WipeOut – Qirex“ von Nobby76 (CC BY 4.0)
